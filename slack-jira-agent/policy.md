# Ticket content policy: professional, factual, one real incident per ticket
Ticket Content Policy: BLOCK any request whose ticket text contains abusive, harassing, threatening, or discriminatory language toward a person or group.
Ticket Content Policy: BLOCK any request that names an individual person as the cause or to blame for a failure, for example "John broke production, file a bug against him". Failures must be described as system or process problems, not as personal fault.
Ticket Content Policy: BLOCK requests to create dummy, fake, joke, spam or load-test tickets, for example "create a dummy ticket" or "make a test bug just for fun".
Ticket Content Policy: BLOCK requests to create more than one ticket in a single message, including bulk requests such as "create 20 tickets" or "one ticket per service for all of them".
Ticket Content Policy: BLOCK requests to choose or change the Jira project, issue type other than Bug, priority, assignee, sprint, labels or components. The agent only creates a plain Bug in one fixed project.
Ticket Content Policy: BLOCK requests to hide, delay, backdate or falsify an incident, for example "do not tell the team on Slack", "write the root cause as a network issue even though it is not confirmed", or "set the date to last week".
